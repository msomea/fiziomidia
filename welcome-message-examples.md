## Usage Instructions

### How to Send:
1. Go to Admin Dashboard
2. Open "System Notifications" section
3. Choose "All Users" as target
4. Select appropriate priority level:
   - **Critical**: For urgent account actions
   - **Important**: For required profile setup
   - **Update**: For new features/changes
   - **Information**: For general welcomes
5. Copy and paste your chosen message
6. Click "Send Notification"

### Best Practices:
- Keep messages concise and friendly
- Use emojis to make messages engaging
- Include clear calls-to-action when needed
- Match priority level to message urgency
- Test message formatting before sending

### Timing Considerations:
- Send welcome messages within 24 hours of user registration
- Use information priority for general welcomes
- Use important priority for action-required messages
- Avoid sending multiple welcome messages in short succession

These templates are designed to be professional, welcoming, and effective for engaging new users with the FizioMidia platform!
